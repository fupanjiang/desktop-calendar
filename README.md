# 桌面日程

桌面悬浮日历日程管理工具，支持照片附件、语音输入、定时提醒。

## 功能

- **日历视图** — 月视图日程总览，点击日期查看详情
- **日程管理** — 标题/日期/时间/分类/备注/照片，完整信息
- **定时提醒** — 提前 5 分钟 ~ 1 天，系统通知不遗漏
- **语音输入** — 百度 STT + Windows SAPI 双引擎保底
- **暗色/亮色主题** — 一键切换
- **分类标签** — 工作/个人/健康/会议/其他，色标区分
- **开机自启动** — 可选随系统启动
- **最小化到任务栏** — 关闭按钮收至托盘

## 技术栈

Electron 35 + 原生 HTML/CSS/JS，打包为便携版和 NSIS 安装版。

## 快速开始

```bash
npm install
npm start
```

## 构建

```bash
npm run build              # 便携版
npm run build:installer    # NSIS 安装包
```
